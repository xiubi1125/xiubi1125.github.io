见过第一层的正则

（无参rce）

\w表示非单词字符，单词字符包括：a-z、A-Z、0-9，以及下划线，加上取非^就成了匹配所有的单词字符，+表示可以进行多个匹配，还匹配了左括号和右括号

这个没见过

(?R)?)是正则表达式的一个递归子模式，将匹配到的东西替换为空，然后判断替换后内容是否等于分号

注意：这里第一个匹配替换再进行比较的限制，并不是过滤掉了这些哦，而是让我们只能用这些字符，即所有单词字符、括号和分号，因为只有这样，替换之后才只剩下分号，才能与左边相等，使if语句成立，才会继续执行后面的代码。

var_dump被过滤了 用print_r打印

这里还要用到两个函数

array_flip：反转键值

array_rand：随机取一个键名

比如我们上面打印出来的东西：

[User-Agent] => Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/114.0.0.0 Safari/537.36 Edg/114.0.1823.86

前面的User-Agent叫做键名，后面的内容就是键值。

执行流程：

  1. getallheaders() 拿到请求头数组。

  2. array_flip 交换键名键值，使得我们的命令 "ls /" 变成 键名。

  3. array_rand 随机取一个键名，可能取到 "ls /"。

  4. system("ls /") 执行命令。

    然后我们需要去构造一个键名（随意） 键值（想执行的命令）
