Lazysysadmin靶机渗透

ip检测

打开靶机发现需要登录

内网主机探测中，可以使用nmap来进行

129是kali的地址 出现的192.168.23.132就是靶机ip地址

端口扫描

masscan扫端口（也可以用nmap：nmap -T4 -A -v 192.168.23.132 -p 0-10000 不过比较慢）

masscan 192.168.23.132 -p 1-10000 –rate=1000

目标机开启了22、80、139、445、3306、6667这几个端口

信息收集

扫一下目录

扫出来挺多东西的

先看一下robots.txt

只有最后一个文件里面有东西

点开看了下也没什么用

我们查看wordpress站点

针对 WordPress 的安全测试有一套标准化的流程（确认站点 → 枚举信息 → 漏洞探测 → 利用验证），这和测试普通自定义开发的 Web 站点有明显区别。

扫一下

发现登陆界面

我们已经确定这是wordpress站点

使用专门的工具wpscan进行一下检测

出来的信息比较多

有一个用户枚举 发现了admin

直接来进行一个爆破

失败了

另一个phpmyadmin页面要登陆

继续扫

爆破失败

目前为止这两个部分没办法继续往下了

之前扫端口的时候139和445用于Samba服务，一般攻击方向为爆破、未授权访问、远程代码执行

smb枚举探测

139和445是高危端口，先将靶机的共享目录文件输出

enum4linux -S 192.168.23.132

有共享文件夹

进行挂载

WordPress 的数据库连接信息（数据库名、用户名、密码、主机地址）都存储在 wp-config.php 文件中，使用 cat 命令直接查看

拿到账号密码

TogieMYSQL12345^^

没什么用 这个admin是个没权限的

登录

这里能看到密码12345

成功登录

ssh连接

进行ssh连接

sudo bash提权

这里刚好togie有root权限，所以直接用sudo su切换到root权限，但是如果togie没有root权限，那么我们就需要通过其他方式来提权了。
